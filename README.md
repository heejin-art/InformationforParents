# BEE CLASS 학부모 안내 페이지

디자인 시안을 바탕으로 제작한 반응형 원페이지 웹사이트입니다.

## 실행

별도의 빌드 과정 없이 `index.html`을 브라우저에서 열면 됩니다. 로컬 서버를 사용하려면:

```bash
npx serve .
```

## 이미지 교체

`assets` 폴더에 아래 파일명으로 이미지를 추가하면 현재 플레이스홀더가 자동으로 이미지로 바뀝니다.

- `hero-child.png` — 메인 인물/태블릿 이미지
- `app-devices.png` — 앱 태블릿/휴대폰 이미지
- `work-01.jpg` ~ `work-08.jpg` — 학생 작품 이미지

다른 파일명을 사용하려면 `index.html`의 각 요소에 있는 `data-image` 값을 변경하세요.
